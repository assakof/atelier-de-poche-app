# Atelier de Poche

Application mobile Android de gestion pour les ateliers de réparation de téléphones — développée par **KA Maintenance & Services**.

## Télécharger

👉 Télécharge la dernière version depuis l'onglet **[Releases](../../releases/latest)** de ce dépôt (fichier `.apk`).

Après téléchargement sur ton téléphone Android :
1. Ouvre le fichier `.apk` téléchargé.
2. Si Android affiche un avertissement "Source inconnue", autorise l'installation (c'est normal pour une app distribuée hors du Play Store).
3. Installe et ouvre l'application.

## Fonctionnalités

- Gestion des fiches de réparation (client, appareil, panne, prix, statut)
- Gestion du stock et des ventes d'accessoires
- Caisse du jour
- Notification client automatique par WhatsApp
- Fonctionne 100% hors connexion (mode Gratuit)
- Version Pro disponible : données centralisées, plusieurs appareils, plusieurs techniciens
